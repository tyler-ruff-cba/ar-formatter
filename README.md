# A/R Formatter (Desktop App)
Desktop application build with Electron which formats Weekly 7 spreadsheets to be processed by the A/R Processor app.

## Build Instructions

To build, first ensure your computer has Node.js and NPM installed.

1. Install NPM packages, navigate to the root of the project and run (in a command prompt/Bash terminal/Powershell):
```sh
npm install
```
2. Once the NPM packages are installed, all you have to do is run the following command at the root of the project:
```sh
npm start
```
